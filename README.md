# Agentic Systems

This project contains learning materials, notebooks, and code related to AI agents, multi-agent collaboration, Retrieval-Augmented Generation (RAG), structured outputs, and agent workflows.

## Directory Structure & Materials

### 1. Fundamentals A: Agents and Crews
* **[01_Agents_and_Crews.ipynb](Fundamentals_A/01_Agents_and_Crews.ipynb)**: Introduction to AI Agents, Tasks, RAG, and basic multi-agent collaboration using the CrewAI framework.
* **[config.yaml](Fundamentals_A/config.yaml)**: Configuration file defining agents and tasks.
* **[output.md](Fundamentals_A/output.md)**: Sample output generated by the agents in this module.

### 2. Fundamentals B: Structured Outputs and Tools
* **[02_Structured_Outputs.ipynb](Fundamentals_B/02_Structured_Outputs.ipynb)**: Guide on ensuring agents return clean, structured outputs (for easy downstream parsing) and integrating external tools for real-world queries.
* **[research_crew.py](Fundamentals_B/research_crew.py)**: Python script for running the multi-agent research crew workflow.
* **[config/](Fundamentals_B/config/)**: Directory containing `agents.yaml` and `tasks.yaml` for this module.

### 3. Flows in Agentic AI
* **[notebook.ipynb](Flows-in-Agentic_A/notebook.ipynb)**: Starter notebook exploring advanced agentic flow patterns and state management.
